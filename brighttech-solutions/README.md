# BrightTech Solutions Website

A responsive student project built with HTML5 and CSS3 only.

## Files
- `index.html` — website content and sections
- `style.css` — layout, responsive styles, and blue-and-white theme
- `images/` — locally stored SVG illustrations and placeholder portraits

## Open the website
Open `index.html` in a web browser. No installation or build process is required.

## Before submitting
- Replace sample employee names, bios, and placeholder portraits with your actual team details.
- Replace example contact details with real company contact information.
- Product prices are illustrative.
- The team details and contact forms are HTML/CSS demonstrations. They do not store data or send messages.
- Upload the project to a GitHub repository and enable GitHub Pages if required by your course.
